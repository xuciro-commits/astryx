## Intent

DateTimeInput 在一个字段标签下，把一个受控日期时间值呈现为协同的日期与时间分段。根据 `presentation`，这些分段使用 Astryx 弹出层、一个协同的底部面板、浏览器或操作系统输入，或这些界面的指针自适应组合。

## Compatibility and migration

- 已发布默认值保留：`yes`，但 `hourFormat` 除外，它遵循 provider 区域设置的小时周期（`en` 和 `en-US` 为 `12h`，没有 provider 时为已发布的默认值），并共享 TimeInput 的区域设置时间文本
- 兼容性类别：对非英语美国区域设置的默认值变更；增量的 `calendar` prop，默认公历；键入的公历日期仅在输入完整时触发 `onChange`（FR11）；非公历日历会把原生控件替换为面向指针的 Astryx 界面，并且显式 `native` 在开发时会警告（FR12）；增量的 `onEntryErrorChange` prop 对省略它的调用方没有任何改变（AR5）；现有类型、回调、角色和导出保持稳定。带 `-u-ca-` 关键字的 provider 区域设置保留公历日期（`spec:AST-111` DEC-2）；设置 `calendar` 以选择其一。`entryErrorBehavior` 是增量的；其默认值 `'complete'` 是已发布行为（FR15、`spec:AST-117`）。未完成的条目不显示拒绝，被拒绝的文本在失焦后保留，拒绝显示一条消息，Enter 提交时间分段并仍然提交表单（FR16）：这是随补丁发布的可访问性行为修复（`spec:AST-017` FR53、`spec:AST-118`）。
- 受控/非受控行为：DateTimeInput 保持受控；`undefined` 表示没有已提交的日期时间值
- 迁移决策：无；选择器呈现和已弃用的 `nativePicker` 兼容性仍由 `spec:AST-043` 管辖

使用方迁移说明属于使用方文档和发布说明。

## Ownership boundary

**拥有**

- 把日期和时间分段协同为一个受控的 ISO 日期时间值。
- 选择并组合由 `presentation` 选定的日期和时间界面。
- 应用组件本地的日期时间边界、日期约束、时间精度、键入时间步进以及可选的预设时间行为。
- 在可选的乐观 `changeAction` 之前发出 `onChange`。
- 禁用原因 Tooltip 的合成，`family:input-fields` 把这项工作分配给该成员。

**不拥有 / 非目标**

- 字段标签、描述、状态和清除按钮的呈现 —— 由 `family:input-fields`（共享所有者小节）下的 Field 和 `component:FieldStatus` 拥有。
- 日历网格渲染和日期单元格交互 —— 由 Calendar 拥有。
- 弹出层和面板的宿主或关闭 —— 由组合的层组件和 `family:overlay-dismissal` 拥有。
- 面板滚轮的静止、运动、滚动输入和外观 —— 由 `component:DateInput` 拥有（FR13–FR15、DEC-1、DEC-2）。
- 跨组件的选择器呈现词汇和已弃用 prop 映射 —— 由 `spec:AST-043` 拥有。

### Allowed variation

- **AV1 — 界面。** 调用方可以强制 Astryx、原生或底部面板界面，或在当前系统规格矩阵内选择自适应呈现。
- **AV2 — 日期和时间格式化。** 区域设置、小时格式、秒、周起始、月份数量以及预设步长可以通过其文档化输入变化。
- **AV3 — 可选字段支持。** 清除、加载、状态、禁用原因、描述以及标签可见性可以省略，而不改变值所有权。

### Transformation and precedence order

- **ORD1 — 选择器选择。** 在已弃用的 `nativePicker` 之前解析 `presentation`；当日历不是 `gregory` 或 `iso8601` 时，用 `adaptive-bottom-sheet` 代替 `native` 和 `adaptive-native`（FR12）；应用指针自适应，然后只应用 `spec:AST-043` 允许的逐分段原生回退。
- **ORD2 — 值变更。** 校验提议的分段值，将其与已提交的对应部分合并，调用 `onChange`，呈现乐观的合并值，然后在过渡中运行 `changeAction`。

### Performance and resources

- **PR1 — 预设选项。** 时间列表框仅在打开时挂载选项节点；省略预设步长不会留下任何列表框节点或 combobox 语义。

当前测量值属于审计记录；本小节只拥有持久约束及其验证目标。

## Accessibility contract

- **AR1 — 字段命名。** 日期分段由字段标签命名；时间分段使用 `timeLabel` 或由标签派生的本地化回退。描述、状态和禁用原因文本仍从两个分段引用。
- **AR2 — 选择器语义。** Astryx 日期分段是一个控制 dialog 的 combobox；可选的预设时间字段是一个控制单个列表框的 combobox。省略预设步长时，时间字段没有 combobox 语义。
- **AR3 — 键盘和焦点。** 文档化的键盘激活、日期弹出层关闭、预设时间导航、焦点约束和焦点恢复在其活动界面上保持可操作。
- **AR4 — 必填、无效、忙碌和禁用。** 两个可编辑分段都暴露适用的必填、无效、忙碌和禁用状态；可聚焦的禁用原因绝不会重新启用变更。分段的无效状态遵循 FR15。
- **AR5 — 键入日期拒绝和日历。** 不可读的文本、日历中不存在的日期以及超出范围的日期各自从日期分段播报不同的目录消息，并且各自还将其显示为字段的错误状态（FR16），在被拒绝的文本保留期间取代调用方 `status`（`spec:AST-111` AR3）。使用 `onEntryErrorChange` 时，带消息的调用方 `error` 状态会取代字段的消息进行显示和播报，而 `warning` 或 `success` 状态绝不会替换拒绝，如 `component:DateInput` AR3 所述。字段状态自身播报，日期分段的警报只携带没有任何状态播报的拒绝消息，因此每条消息只播报一次；在未改变的调用方错误消息之下开始的拒绝，由该警报播报一次，如 `component:DateInput` AR3 所述。指针日期分段的描述仅当其解析出的日历不同于 provider 解析出的日历时才指明该日历，否则为 `gregory`，`gregory` 和 `iso8601` 视为一个日历，两者都在对没有 `Temporal` 的运行时应用公历回退之后进行比较。当日历不是 `gregory` 或 `iso8601` 且没有调用方 `placeholder` 时，空的聚焦分段以该日历的数字模式显示一个示例日期；调用方 `placeholder` 在每个状态下都显示，并替换该提示。示例日期在字段接受它时为今天，否则为字段接受它的最近日期（`spec:AST-111` AR2）。

### `spec:AST-013` FR12 exception — calendars that need `Temporal`

- **能力：** 在公历、佛历、民国历和日本历之外的日历中，键入日期条目、已提交日期文本以及底部面板的 Date 面板需要运行时的 `Temporal`。
- **缩减：** 在缺少 `Temporal` 的地方，如 macOS 和 iOS 上的 Safari，日期分段读取、写入和显示公历日期，其呈现按 `gregory` 的方式解析，并在开发时警告一次，指明一个 polyfill（`spec:AST-111` FR5）。加载 `Temporal` polyfill 的应用程序获得完整的日历。当服务器和浏览器使用的中国历或 Dangi 历实现在某个月起始上不一致时，React 会在客户端再次渲染不同的文本（`spec:AST-111` FR19）。
- **保留的义务：** `spec:AST-013` FR7 和 FR8，以及该中国历和 Dangi 历情况之外的 FR9。公历日期和时间分段保留每次交互、标签和播报，佛历、民国历和日本历条目在没有 `Temporal` 时也能工作。
- **证据：** 在带原生 `Temporal`、移除 `Temporal` 并加载 polyfill、移除 `Temporal` 且不加载 polyfill 三种情况下，于真实 Chromium 和 Firefox 中在日历字段里键入，经由共享的 DateInput 字段；在相同的三种模式下，于真实 Chromium、Firefox 和 WebKit 中的共享底部面板。
- **所有者：** `nynexman4464`。
- **审查条件：** Safari 发布 `Temporal`。

## Current-state impact

- **固定高度（FR5）。** 分段保持共享的固定元素高度，而不是随设定的文本大小增长，这与 `spec:AST-102` FR4 相抵触。
- **键入时间的前缀提交（FR7）。** 键入的时间字段会提交已解析的前缀，因此键入的时间可能提交成另一个时间，这与 `architecture:internationalization` INV8 相抵触。
- **忙碌态绘制（FR9）。** 处于忙碌但未禁用的字段会采用禁用态的半分透明绘制，这与 `spec:AST-085` FR6 相抵触。
- **禁用期间的调用方处理函数（FR9）。** 日期分段上的调用方 DOM 处理函数（例如 `onKeyDown`）在禁用期间仍会运行，这与 `spec:AST-085` FR2 相抵触。
