# Button component contract

## Contract at a glance

| 领域          | 契约                                                                                                                                                                                                                                                     |
| ------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 公共契约      | 无变更。本记录陈述已发布的 Button 表面：`label`、变体、尺寸、elevation、内容模式、loading 与 `clickAction`、`isInterruptible`、disabled、tooltip、宽度、表单属性，以及链接模式。                                                                         |

## Intent

Button 是该家族中瞬时动作控件。它拥有 `family:buttons` 指派给它的共享动作表面：原生按钮语义、可访问命名、尺寸、视觉变体、按压与焦点反馈、待处理呈现、链接模式，以及静止态 elevation。使用方用法见 `Button.doc.mjs`。

## Compatibility and migration

- 已发布的默认值保留：`yes`；`variant="secondary"`、`size="md"`、`elevation="none"` 和 `type="button"` 是默认值
- 兼容性类别：记录已发布的行为；没有公共 prop、默认值、导出或 DOM 变更
- 受控/非受控行为：不适用；Button 不持有任何值。待处理状态来自 `isLoading`，或来自进行中的 `clickAction`
- 迁移决策：无

使用方迁移说明应放在使用方文档与发布说明中。

## Ownership boundary

**拥有**

- 动作表面：根元素选择、可访问名称、内容顺序、尺寸、宽度与截断、变体绘制、悬停、按压与焦点反馈。
- click 与 `clickAction` 的时序、一次性去重，以及可中断的退出选项。
- 待处理呈现：Spinner 覆盖层、隐藏内容、`aria-busy`，以及加载播报区域。
- 粗指针下的触摸带（`spec:AST-094` FR42），由内容包裹元素的 `::after` 承载；根元素的 `::before` 与 `::after` 保持为 FR15 所述，供调用方使用。
- 仅忙态与 disabled 的可操作性守卫。
- 链接模式的渲染选择及其 disabled 回退。
- 独立的静止态 elevation 与 `button` 主题目标。
- ghost 变体的边缘补偿标记。

**不拥有 / 非目标**

- 连接组的圆角、分隔线、继承的 disabled 状态、游走焦点，以及共享 elevation —— 由 `component:ButtonGroup` 在 `family:buttons` FR8 与 FR12 下拥有。Button 绘制组上下文提供的内容。
- InputGroup addon 的几何 —— 由 `component:InputGroup` 拥有。
- 作为专用组件的仅图标 —— 由 `component:IconButton` 拥有。
- 持久按压状态 —— 由 `component:ToggleButton` 拥有。
- 目标接受与自定义路由器交接 —— 由 `family:navigation-destinations` 和 `spec:AST-005` 拥有。
- Tooltip 的外观、时序与关闭 —— 由 `component:Tooltip` 拥有。
- Spinner、Icon 与 Badge 的渲染 —— 由那些组件拥有。
- 触摸按压控制器与 `usePressFeedback` —— 未纳入契约的共享 hook；Button 只是组合它们。

### Allowed variation

- **AV1 — 主题绘制。** 主题可以更改变体颜色、圆角（通过 `button` 目标）、焦点偏移（`--button-focus-offset`），以及仅图标的宽高比，而不改变结构、命名或可操作性。
- **AV2 — 自定义变体。** 模块增强的变体可以完全由主题通过 `data-variant` 绘制；Button 只提供基础表面。
- **AV3 — 可见内容。** `children` 与 `endContent` 可以是任何调用方内容；Button 不检查它们。

### Transformation and precedence order

- **ORD1 — 尺寸。** 显式 `size`，然后是最近的尺寸提供者，然后是 `md`。
- **ORD2 — 可用性。** Disabled，然后是仅忙态，然后是可操作。可中断的待处理属于可操作。
- **ORD3 — 元素。** 仅当提供 `href` 且 Button 未 disabled 时为链接模式；否则为 `<button>`。
- **ORD4 — 可访问名称。** Button 在以下情况把 `aria-label` 设为 `label`：它是仅图标且标签非空；它处于待处理且不是仅图标；或 `children` 与 `label` 不同；该值优先于调用方的 `aria-label`。否则，若调用方给出 `aria-label`，则由它命名 Button；若没有，则 Button 由其渲染内容命名：`icon` 槽中的任何文本、标签文本，以及 `endContent` 中的任何文本。装饰性 Astryx Icon 不为其名称添加任何内容。
- **ORD5 — 样式。** 变体绘制应用在共享焦点轮廓之上，因此 destructive 焦点环取 error 颜色；调用方 `xstyle` 在 Button 自身样式之后应用，然后合并 `className` 与 `style`。

### Performance and resources

- **PR1 — 无空闲工作。** 以空闲状态挂载的 Button 不会为其加载区域安排任何工作。只有首次渲染即为待处理的 Button 会把该区域的文本推迟一个动画帧（AR4）。

## Accessibility contract

- **AR1 — 名称。** 每个 Button 都有可访问名称（ORD4），正如 `family:buttons` FR1 所要求：当 Button 设置 `aria-label` 时取自 `label`，否则取自调用方的 `aria-label` 或渲染内容，后者包含标签文本。仅图标场景中的图标绝不会替代该名称。
- **AR2 — 键盘。** `<button>` 通过 Enter 与 Space 激活；链接通过 Enter 激活。焦点顺序即 DOM 顺序。
- **AR3 — 焦点指示器。** 键盘焦点在 `--button-focus-offset` 处绘制共享焦点轮廓；destructive 变体用错误色为其着色。可见性遵循 `architecture:interaction-modality` INV1。
- **AR4 — 加载播报。** Button 渲染一个持久的、视觉上隐藏的 `role="status"` `aria-live="polite"` 区域。它在待定时承载本地化的加载字符串，其余时候为空。首次渲染即处于待定状态的 Button 会先以空内容挂载该区域，并在下一帧填充（`spec:AST-086` FR3）。在 live 容器内，它保持自身的角色与紧急程度（`spec:AST-086` FR4）。语音输出遵循 `spec:AST-009`。
- **AR5 — 忙碌与禁用暴露。** 待定状态设置 `aria-busy`。仅忙与禁用的 Button 必须在可聚焦元素上暴露 `aria-disabled="true"`（`spec:AST-085` FR5）。禁用的 Button 绝不渲染原生 `disabled`。
- **AR6 — 目标尺寸。** 每个 Button 至少 28 CSS 像素高，除非调用方的高度替换其尺寸（FR4）。在默认方形宽高比且无 `width` 时，仅图标 Button 至少为 28 × 28；在拥挤的行中，带标签的 Button 收缩的下限是其 24 CSS 像素的行内内边距。两者都满足 WCAG 2.5.8 的 24 × 24 最低要求。调用方的 `width` 或主题的仅图标宽高比若使 Button 窄于 24 CSS 像素，或调用方高度低于 24 CSS 像素，则其目标尺寸由该调用方或主题负责。
- **AR7 — 强制颜色边缘。** 在强制颜色下，实心变体（仅凭填充就与页面区分的变体）保留可见的 1 px 系统颜色边框，因此在强制颜色替换填充时其形状仍然可见（`spec:AST-020` FR1，WCAG 2.2 SC 1.4.11）：`ButtonText`，或在 `destructive` 上使用 `CanvasText`（`architecture:theme-tokens` INV11）。在 ButtonGroup 中，分组的分隔线保留，其首尾按钮封闭分组的外缘，且没有加倍的接缝。`ghost` 保持无边框。在强制颜色之外不添加边框。设置实心变体自身边框宽度的主题会保留该设置。

实现缺口：在深色强调色上，Button 的悬停与按下覆盖层使其标签的对比度为 4.35:1 和 4.02:1，低于 4.5:1。

## Current-state impact

- FR15 的鼠标与笔通过按压控制器的按压尚未实现：鼠标按压仍以 `:active` 绘制（`spec:AST-094` DEC-21）。
- **变为禁用的链接 Button（FR11）。** 已聚焦的链接 Button 变为禁用后会失去焦点，无论是否有 `tooltip`，因为其锚点被替换为 `<button>`（`spec:AST-085` FR4）。
- **水合前的隐式提交（FR9、FR10）。** 在水合之前，在只有一个提交 Button 且该 Button 处于禁用或加载中的单字段表单里，按 Enter 仍会提交，因为纯 HTML 在没有原生 `disabled` 的情况下无法阻止隐式提交。
- **使用方文档。** `Button.doc.mjs` 将 Spinner 描述为替换图标；它实际覆盖所有内容（FR8）。中文的 `isLoading` 文本称加载会禁用交互，其 `icon` 文本称没有 children 的图标会渲染方形按钮；仅图标取决于 `isIconOnly`（FR2）。
- **末尾内容文档类型（AV3）。** `Button.doc.mjs` 将 `endContent` 类型标为 `ReactElement<IconProps> | ReactElement<BadgeProps>`，其中文文本称它只接受 Icon 或 Badge，而 `ButtonProps` 将其标为 `ReactNode`，任何调用方内容都会渲染。
- **减少动态效果下的 Spinner 淡入（FR8）。** 在精细指针下，即使使用者偏好减少动态效果，Spinner 仍会在快速时长内淡入，这违反 `design:reduced-motion` DR3。
- **加载时自带颜色的末尾内容（FR8）。** 绘制自身颜色的 Badge 或其他内容会在 Spinner 旁保持可见。
