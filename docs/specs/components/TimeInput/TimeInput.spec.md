## Intent

TimeInput 以 ISO 字符串收集一天中的某一个时间。它拥有时间解析、范围检查、方向键步进、在 `spec:AST-043` 下于文本输入、原生与面板表面之间的选择，以及在 `family:input-fields` 下对 Field 与 InputGroup 的适配。使用方用法见 `TimeInput.doc.mjs`。

## Compatibility and migration

- 保留已发布的默认值：对 `hourFormat` 为 `no`（它跟随 provider 区域设置的小时周期，`en` 与 `en-US` 为 `12h`，没有 provider 时即已发布的默认值）；对 `presentation="adaptive-native"`、`increment={1}`、无秒、无清除、`size="md"`、`statusVariant="attached"` 为 `yes`
- 兼容性类别：对非 en-US 的区域设置属于默认值变更；除增量式的 `entryErrorBehavior`（其默认值 `'complete'` 即已发布的行为，FR13，`spec:AST-117`）与可选的 `onEntryErrorChange` 之外，没有公共属性、类型、导出或 DOM 变化；未完成的草稿不显示拒绝，被拒绝的草稿在失焦后保留，Enter 是一次仍会提交表单的提交，拒绝会显示一条消息（FR14、FR15）：这是一项随补丁发布的无障碍行为修复（`spec:AST-017` FR53、`spec:AST-118`）
- 受控/非受控行为：受控；`value` 是 ISO 时间或 `undefined`，只有在 `changeAction` 尚未完成期间，输入框才显示乐观值
- 迁移决策：`nativePicker` 仍作为 `spec:AST-043` FR3 中已弃用的映射

使用方迁移说明属于使用方文档与发布说明。

## Ownership boundary

**拥有**

- 表面的选择及其回退。
- 文本输入框：解析、草稿、提交、无效输入播报，以及方向键步进及其播报。
- 内部 hook `useTypedTime`（`packages/core/src/TimeInput/useTypedTime.ts`）。它拥有键入草稿、草稿的完成时点、在 Enter 与失焦时的提交、保留的草稿及其提交的表单值，以及对原生时间控件的拒绝（FR11、FR14）。DateTimeInput 的时间分段使用它，因为 `component:DateTimeInput` FR16 把 FR14 的规则赋予该分段，正如它使用原生时间控件一样。族 hook `useEntryErrorReport` 只拥有拒绝的状态、警报与上报，而 `useTypedDate` 读取日期，因此两者都不持有时间规则。
- 原生时间控件的集成与底部面板时间滚轮。
- 变更与动作管线、忙碌状态以及清除。
- 禁用与禁用原因行为；`time-input` 目标；其分组适配。

**不拥有 / 非目标**

- 标签、描述、状态消息的位置、标签 tooltip 以及 `width`——由 `family:input-fields` 下的 Field 拥有（共享所有者小节）。
- 浏览器时间选择器自身的界面——由平台拥有。
- BottomSheet 托管——由 `component:BottomSheet` 拥有；面板滚轮的静止、运动、滚动输入与外观——由 `component:DateInput` 拥有（FR13–FR15、DEC-1、DEC-2）。
- 日期与时间的组合——由 DateTimeInput 拥有。
- 只读——不提供。

### Allowed variation

- **AV1 — 原生选择器界面。** 平台决定其选择器的外观与步进方式。
- **AV2 — 可接受的键入形式。** 共享时间解析器决定哪些键入拼写可解析。一次解析必须提交此人键入的时间，绝不是一个不同的时间（FR3 缺口：前缀提交）。

### Representative states

| State                | Required invariant                                  | Allowed variation |
| -------------------- | --------------------------------------------------- | ----------------- |
| 精细指针，默认       | 带时钟图标的文本输入框。                            | 小时格式。        |
| 粗糙指针，默认       | 原生时间选择器，除非有秒或步进不为 1。              | 平台界面。        |
| 强制 `native` 且有秒 | 仍然是原生选择器。                                  | —                 |

| 无效的键入草稿       | 按 FR14：错误状态；`aria-invalid`；一次播报；保留。 | —                 |

### Transformation and precedence order

- **ORD1 — 表面。** 先取 `presentation`，否则取 `nativePicker` 的映射，否则取 `adaptive-native`；然后取指针；然后应用自适应与旧式原生回退。
- **ORD2 — 变更。** `onChange`，然后是乐观值与 `changeAction`。
- **ORD3 — 面板滚轮。** 由滚轮合成时间，其中跨过接缝保持小时 → 夹取到范围 → 若有变化则提交。

### Performance and resources

- **PR1 — 指针查询。** 每个实例一个粗糙指针媒体查询决定表面（原生表面的分段会添加自己的查询）；文本输入框不添加任何测量。

## Accessibility contract

- **AR1 — 名称与描述。** 独立使用时，控件由 Field 标签（加上任何调用方的 `aria-labelledby`）命名，并由描述、状态消息或状态 tooltip、禁用原因以及调用方描述来描述。在 InputGroup 内部，它按 FR10 命名和描述，包括其在面板表面与 tooltip 状态变体上的缺口。
- **AR2 — 播报。** 被拒绝的键入草稿与超出范围的原生编辑会显示一条消息、设置 `aria-invalid`，并按 FR14 所述以 assertive 只播报一次、与其他信号一同出现，绝不在草稿未完成时播报，且在 `entryErrorBehavior="blur-or-enter"` 下于 Enter 或失焦时播报（FR13）；有调用方 `error` 状态时，该状态会显示，且拒绝只播报一次（FR15）；在 InputGroup 内部，拒绝会被播报并设置 `aria-invalid`；步进的时间以礼貌方式播报（FR4）；文本输入与原生表面上的分组状态消息通过共享通道播报（FR10；面板表面是一个缺口）。
- **AR3 — 禁用。** FR9 在每个表面上满足 `spec:AST-085` FR1 与 FR6；FR2 的缺口已在那里注明。
- **AR4 — 面板语义。** 面板字段是一个只读组合框，它报告其打开状态并打开一个对话框。实现缺口：它只能由指针打开（FR7）。

## Current-state impact

- **面板键盘访问（FR7, AR4）。** 面板表面只能通过点按或点击打开，其时钟按钮不在 tab 顺序中，因此键盘用户无法在那里设置时间，这违反 `architecture:interaction-modality` INV4。
- **面板与原生清除焦点（FR8）。** 在面板或原生表面上清除后，键盘焦点留在文档 body 上。
- **分组面板字段（FR10）。** 在 InputGroup 内部，面板字段仅由组标签命名，引用了缺失的描述与状态 id，且不播报自己的状态消息。
- **清除按钮焦点（FR9）。** 一个已聚焦的清除按钮在字段变为禁用时消失，焦点掉到页面上，这违反 `spec:AST-085` FR4。
- **减弱动态效果下的按钮按压（FR8）。** 当用户偏好减弱动态效果时，清除按钮与面板的 Save 按钮在按压时仍缩放到 0.98，如 `component:Button` FR15 所记录，这违反 `design:reduced-motion` DR1。
- **禁用时的调用方处理函数（FR9）。** 禁用的 TimeInput 仍会运行调用方除焦点与失焦之外的 DOM 处理函数，例如 `onKeyDown`，只阻止 `onClick`，这违反 `spec:AST-085` FR2。
- **格式提示（FR5）。** 当已聚焦的字段变为禁用时，聚焦且为空时的格式提示会保持显示直到失焦。
- **忙碌时的拒绝（FR13）。** 忙碌的 TimeInput 仍可编辑，但在空闲之前不显示自己的任何拒绝，这违反 `spec:AST-117` FR6。
- **键入解析（FR3, AV2）。** 键入字段提交解析出的前缀，因此键入的时间可能提交为另一个时间，这违反 `architecture:internationalization` INV8。
- **滚轮数字（FR5）。** 面板的时、分、秒滚轮在所有语言环境中使用 ASCII 数字，这违反 `architecture:internationalization` INV1a 与 INV8。
- **分组的提示状态（FR10）。** 在 InputGroup 内且 `statusVariant="tooltip"` 时，键入与原生字段从不通过 `aria-describedby` 引用隐藏的状态消息。
- **继承自 TextInput 的缺口（FR12）。** 固定高度（`spec:AST-102` FR4）、仅靠颜色与图标显示且无消息的错误状态（WCAG 2.2 3.3.1），以及 `component:TextInput` 记录的、无消息且仅靠颜色的 `detached` 状态（WCAG 2.2 1.4.1），在此同样适用。
- **源码注释。** `TimeInput.tsx` 中的 `size` JSDoc 给出 18 px 与 26 px 高度；实际交付的高度来自共享元素尺寸。
