## Intent

CommentPin 是用于打开单个锚定标注讨论串或调用方定义的讨论串组的紧凑交互界面。它在锚点处保留人的身份线索，同时仍可在内容之上或内容边距中使用。

## Compatibility and migration

- 保留的已发布默认值：`not yet released`
- 兼容性类别：增量式实验性 Lab API
- 受控/非受控行为：选中、变暗、已解决与已禁用状态以及未读数均由调用方控制；组件不拥有任何选择或已读状态
- 迁移决策：无；在 Lab 契约被接受后，调用方替换定制的标注标记视觉

使用方迁移说明属于使用方文档与发行说明。

## Ownership boundary

**拥有**

- 一个按钮表面、其单个/分组的视觉变换、其三种尺寸，以及其选中、变暗、已解决、已禁用、悬停、按下和焦点可见的呈现。
- 通过 `Avatar` 渲染有序的参与者数据，对于分组则通过 `AvatarGroup` 配合不可交互的 `AvatarGroupOverflow` 渲染，且不使后代变为可交互。
- 当被表示的讨论串总数大于一时显示该总数，随后只要未读数大于零就显示强调色的 `StatusDot`。
- 对未选中的已解决标记不渲染任何内容。
- 稳定的 `comment-pin` 主题目标与状态反射。

**不拥有 / 非目标**

- 讨论串数据、未读跟踪、授权、加载、传输、选择状态，或激活时打开的面板——由产品调用点拥有。
- 聚类、参与者排序、锚点身份、坐标、碰撞处理、图像变换、边距布局或连接线——由产品调用点拥有。
- 头像加载/回退、形状与身份绘制——委托给 `component:Avatar`；溢出指示器绘制——委托给 `component:AvatarGroup`。
- 标注的序数编号。讨论串计数是分组标记的数量，绝不是标记的身份。

### Allowed variation

- **AV1 — 参与者身份。** 名称与图像来源各异；Avatar 负责图像加载、初始字母回退与匿名回退。
- **AV2 — 产品放置。** 调用方通过布局组合与受支持的样式输入，将根置于内容之上或内容边距中。绝对锚点坐标映射到逻辑 bottom-start 角，而不是标记的中心。
- **AV3 — 讨论串分组。** 调用方可以使用任意聚类策略与参与者排序，而标记的视觉变换保持固定。
- **AV4 — 主题输出。** 主题可以重新绘制被允许的根目标及其反射状态，而不改变行为或后代 Avatar 的所有权。

### Transformation and precedence order

- **ORD1 — 计数规范化。** 校验 `threadCount`；无效值解析为一，然后大于一的值选择分组呈现。接着校验 `unreadCount`；无效值被忽略，大于已解析总数的值被截断至该总数。
- **ORD2 — 参与者。** 保留调用方顺序并移除重复 ID。单个标记取第一位参与者；分组标记在剩余不同参与者不超过三个时显示每一位，否则显示前两位加上一个省略号溢出圆形。
- **ORD3 — 计数显示。** 分组标记显示总数；已解析的未读数大于零时在其后添加强调色圆点，或在单标记中于参与者之后添加。
- **ORD4 — 绘制。** 未选中的已解决标记不渲染任何内容。否则基础表面、变暗处理、选中处理，然后是禁用处理按该顺序组合。选中的身份保持完全醒目，而禁用交互始终优先。

### Performance and resources

- **PR1 — 有界解剖结构。** 无论被表示的讨论串数量或提供的参与者数量是多少，渲染工作量都被限制在最多三个参与者圆形（Avatar 加溢出指示器）、一个计数元素和一个未读圆点。
- **PR2 — 共享交互资源。** 触摸反馈使用共享的文档级按下控制器，不添加标记本地的监听器、观察器、定时器或状态。

当前的度量数据属于审计记录；本小节仅拥有持久约束及其验证目标。

## Accessibility contract

- **AR1 — 操作。** 根是一个原生 `button type="button"`，由必需的 `label` 命名；`isDisabled` 暴露 `aria-disabled="true"` 并阻断每条激活路径，同时标记保留其 Tab 停靠点（`spec:AST-085`）。
- **AR2 — 选择。** `isSelected` 通过 `aria-pressed`、标记外的一圈实心 2px 强调色轮廓以及强制颜色下的 Highlight 处理来暴露；该轮廓紧贴标记，而共享的 focus-visible 轮廓位于更外侧，因此两种状态保持可区分。当已选中的标记再次被激活时，宿主清除选择。
- **AR3 — 装饰性后代。** 参与者 Avatar、溢出圆形、可见的讨论串总数与未读圆点对辅助技术隐藏，因为由调用方编写的按钮标签拥有完整的操作名称。
- **AR4 — 提示文本。** 操作标签在指针悬停与键盘焦点时以视觉方式可用；激活仍是主要的触摸行为。
- **AR5 — 状态命名。** 当已解决、分组或未读上下文会改变操作含义时，调用方将其包含在 `label` 中；组件不生成特定于应用程序或依赖区域设置的文案。
- **AR6 — 变暗的同级。** `isDimmed` 仅改变呈现。它不得设置 disabled 或 aria-disabled，因为未选中的标记仍是可用于切换选择的可用目标。

### Design decisions

<!-- design-decisions:v1 -->

| ID  | Decision                                                                                                                                                                                                   | Intent or reason                                                                                                                                                                                                                 | Applies to                 | Allowed variation                                      |
| --- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------- | ------------------------------------------------------ |
| DD1 | 参与者 Avatar（而非序数）标识评论标记。                                                                                                                                                                    | 随着标注数量增长，序数身份变得难以浏览和管理。                                                                                                                                                                                   | 单个与分组标记             | 身份数据与 Avatar 回退可以变化                         |
| DD2 | 分组标记最多显示三个参与者圆形——参与人数多于三个时为两个 Avatar 加上一个省略号溢出圆形——并单独显示讨论串总数。                                                                                             | 身份与数量回答的是不同问题；限制头像堆叠的数量可使分组标记在参与人数增长时仍保持紧凑与可浏览，而省略号使总数成为标记上唯一的数字。                                                                                               | 分组标记                   | 调用方选择参与者顺序与分组策略；主题选择省略号字形     |
| DD3 | 选中绘制是标记外的一圈实心 2px 强调色轮廓，以透明边框上的 box-shadow 环绘制；它保留标记的中等高度且不添加强调色填充；共享的焦点轮廓位于更外侧。                                                            | 单圈 2px 轮廓读作选择而非输入框装饰，不产生布局位移，保留 Avatar 区域，并与键盘焦点保持区分。                                                                                                                                    | 选中状态与选中加焦点状态   | 主题强调色与高度令牌可以变化；轮廓宽度、位置与间隔不变 |
| DD4 | 逻辑 bottom-start 角是固定的 2px 逻辑长写属性；其他三个逻辑角为标记高度的一半。                                                                                                                            | 主题可能放大 `--radius-inner`，因此使用字面值可使气泡线索精确保持 2px。半高角无需 9999px 全半径令牌即可完全圆滑，而后者会使浏览器缩放全部四个角以适配并抹去那个小角。显式的逻辑长写属性避免了简写级联冲突，并天然在 RTL 中镜像。 | 每个标记与每种视觉状态     | 三个圆角遵循元素尺寸令牌；2px 锚点角不变               |
| DD5 | 绝对锚点坐标映射到标记的逻辑 bottom-start 角，而非其中心。                                                                                                                                                 | 气泡角保持附着在被标注的点上，而主体向 block-start 与 inline-end 方向生长。                                                                                                                                                      | 置于内容之上或边距中的标记 | 宿主坐标与变换可以变化；锚点角不变                     |
| DD6 | 当某个标记被选中时，同级标记使用受控变暗并保持启用。                                                                                                                                                       | 活动目标获得视觉焦点，同时不妨碍查看者直接切换到另一个标记。                                                                                                                                                                     | 具有一个活动目标的标记集合 | 宿主选择哪些同级属于焦点集合；选中始终优先于变暗       |
| DD7 | 未读讨论串在讨论串总数之后添加强调色的 `StatusDot`，或在单标记中于参与者之后添加；不显示未读数字。                                                                                                         | 圆点使未读活动在每个标记上都保持可见，而不引入与总数竞争的第二个数字。                                                                                                                                                           | 单个与分组标记             | 主题强调色可以变化；圆点在总数之后的位置不变           |
| DD8 | 尺寸 `sm`、`md` 与 `lg` 在元素尺寸令牌上分别为 28、32 与 36px 高，参与者圆形为 22、24 与 28px，四边内边距相等；分组标记的第一个环位于 start 内边距中，而尾随的总数或圆点增加 `--spacing-1` 的 end 内边距。 | 宿主使标记匹配其所标注内容的密度；每个边缘上的同一内嵌量使身份与计数居中，并让单个与分组标记具有相同的边缘节奏。                                                                                                                 | 每个标记                   | 主题可以更改元素尺寸令牌；圆形直径与相等内嵌量不变     |
| DD9 | 已解决的标记除非被选中，否则不渲染任何内容。                                                                                                                                                               | 已解决的讨论离开内容；已选中的标记保留，因此读者打开过、或从其弹出层中解决过的讨论串会保持其锚点，直到宿主清除选择。                                                                                                             | 已解决的标记               | 宿主决定哪些讨论串已解决、哪一个被选中                 |
