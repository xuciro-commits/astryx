## Contract at a glance

| Area                    | Contract                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| ----------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Public contract         | 无变更。Switch 接收 `label`、`value`、`onChange`、`changeAction`、`isLoading`、`isDisabled`、`disabledMessage`、`isRequired`、`isOptional`、`status`、`size`、`labelPosition`、`labelSpacing`、field content 和基础 props。                                                                                                                                                                                                                 |
| Behavior                | 一个原生 checkbox，带 `role="switch"`，绘制为轨道和滑块。一次变更会调用 `onChange`，然后以乐观值调用可选的 `changeAction`；忙碌时，开关在滑块中显示 Spinner 并拒绝变更。它的按下与拖拽对每种指针都有效：滑块跟随拖拽，并在释放后由弹簧落定。在触摸呈现下，一次轻触、一次单击、一次按键或一次 `value` 变更会让它从静止状态由同一弹簧落定；没有触摸呈现时，一次单击、一次按键或一次 `value` 变更会依据主题的运动 token 随释放移动它（FR15）。 |
| End-user impact         | 人们翻动一个立即生效的设置，并在保存时听到提示音。键盘和屏幕阅读器用户可以到达处于禁用状态的开关及其原因。                                                                                                                                                                                                                                                                                                                                  |
| Builder impact          | 无。                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| Compatibility/readiness | 在手指下，长按以及按下后滑开现在会切换开关；在触摸呈现下，每次轻触、单击或按键都会让滑块从静止状态由滑块自身的弹簧落定；在鼠标或笔下，滑块现在跟随拖拽，拖拽越过翻转距离即翻转（FR15）；粗指针的命中区域朝 44 px 增长（FR10）；无 API、默认值或 DOM 变更。`onClick` 之外的调用方处理程序在禁用状态下仍会运行，调用方 ARIA 落在字段根节点上；两者都列在 Current-state impact 下。                                                            |

## Intent

Switch 呈现一个有标签的布尔设置，其变更立即生效。它拥有 switch 控件、它的变更与 Action 管道、忙碌与禁用行为、标签放置，以及该字段的主题化解剖结构。它的按下与拖拽对鼠标、笔和手指都有效：滑块跟随拖拽，并在每个指针下由释放后的弹簧落定；在触摸呈现下，一次轻触、一次单击、一次按键或一次值变更会让它从静止状态由同一弹簧落定，而没有触摸呈现时，一次单击、一次按键或一次值变更会依据主题的运动 token 随释放移动它（FR15）。在触摸呈现下，滑块还会在手指按压时抬起（FR13–FR15）；键盘或辅助技术保持其释放行为。使用方用法见 `Switch.doc.mjs`。

## Compatibility and migration

- 已发布默认值保持不变：手指下为 `no`，此时长按以及按下后滑开现在会切换开关（FR15），鼠标或笔下也为 `no`，此时拖拽会移动滑块并越过翻转距离后翻转（FR15）；键盘和辅助技术为 `yes`；`size="md"`、`labelPosition="end"`、`labelSpacing="hug"`
- 兼容性类别：触摸呈现增加了抬起以及手指的长按和滑开（FR13–FR15），每个指针都按相同的跟随与翻转规则拖拽滑块，并由弹簧落定（FR15），在触摸呈现下，一次轻触、一次单击或一次按键会让滑块从静止状态由同一弹簧落定（FR15），粗指针的命中区域会朝 44 × 44 px 增长（FR10）；每个公共 prop、默认值、导出和 DOM 元素都保持原样
- 受控/非受控行为：仅受控；`value` 为必填，且仅当 `changeAction` 处于待处理状态时，开关才显示乐观值
- 迁移决策：无

使用方的迁移说明属于使用方文档和发布说明。

## Ownership boundary

**Owns**

- switch 字段、轨道、滑块和标签呈现，由现有的 `switch-field`、`switch`、`switch-thumb` 和 `switch-label` 目标表示。
- 原生 switch input，以及它的 name、description、状态和表单参与。
- 变更与 Action 管道、忙碌状态和忙碌播报。
- 禁用与禁用原因行为。
- 轨道的焦点环、悬停色调和按下叠加层。

**Does not own / non-goals**

- 通过专用公共目标设置 description 样式；当前不存在这样的目标。
- 校验消息呈现——由 `component:FieldStatus` 拥有。
- 加载指示器呈现——由 `component:Spinner` 拥有。
- 用于共享标签和禁用原因行为的 tooltip 表面。
- 标签渲染——由 FieldLabel 拥有。

### Motion roles

本记录命名了这些动态角色，生成的动态角色表承载它们（`spec:AST-094` FR4、DEC-5）。每个值都在 UISwitch、iOS 26.2 上度量（`motion/uikit/switch.ts`），主题只能通过其动态旋钮触及它们（`spec:AST-094` DEC-15）。在每一种指针下，开关为一次拖动及其释放播放 `switchControl.tracking` 与 `switchControl.travel`（FR15）。在触摸呈现下，一次点按、一次点击、一次按键或一次 `value` 变化同样从静止状态在 `switchControl.travel` 上停稳，手指按压时滑块在 `switchControl.lift` 上抬起，并在至少 `switchControl.minimumLiftMs` 之后于 `switchControl.settle` 上回落（`spec:AST-094` FR45）；其余各行仍是已度量的参考值，开关不播放它们。实现缺口：在触摸呈现下，开关对每一次变化、点按、点击、按键或 `value` 变化仍播放 `switchControl.wellOn` 与 `switchControl.wellOff`，而不是按 travel 弹簧的节奏改变轨道颜色；在精细主指针下，滑块不跟随拖动，释放也按主题时长停稳。没有触摸呈现时，一次点击、一次按键或一次 `value` 变化在 `--duration-fast` 与 `--ease-standard` 上滑动滑块与轨道颜色，这仍是释放时的行为，不是缺口。

| Role                          | Default                         | Use                                            |
| ----------------------------- | ------------------------------- | ---------------------------------------------- |
| `switchControl.lift`          | 响应 0.23 s，阻尼比 0.55        | 手指按压时滑块的抬起                           |
| `switchControl.settle`        | 响应 0.5 s，阻尼比 0.7          | 抬起之后已抬起滑块的回落                       |
| `switchControl.minimumLiftMs` | 235 ms                          | 回落之前的最短抬起时间，让快速点按也能显示抬起 |
| `switchControl.travel`        | 响应 0.3 s，阻尼比 1            | 释放之后滑块停稳到已提交的一端                 |
| `switchControl.tracking`      | 响应 0.36 s，阻尼比 1           | 滑块追赶拖动的指针                             |
| `switchControl.wellOn`        | 质量 1，刚度 85.38，阻尼 18.48  | 轨道颜色转为开启                               |
| `switchControl.wellOff`       | 质量 1，刚度 246.74，阻尼 31.42 | 轨道颜色转为关闭                               |

### Allowed variation

- **AV1 — 放置。** 标签位置与间距、尺寸、选中状态与禁用状态仍是当前目标的能力，而不是独立的解剖部件。
- **AV2 — 描述。** 描述可以缺失，而其余解剖部件不变。

### Transformation and precedence order

- **ORD1 — 变更。** 禁用或忙碌守卫 → `onChange` → 乐观值与 `changeAction`，除非被阻止。
- **ORD2 — 描述。** 调用方描述、描述、状态消息、禁用原因。

### Performance and resources

- **PR1 — 资源有界。** 每个 Switch 都把禁用原因 tooltip 的指针、鼠标与焦点监听器挂到它的行上，无论它是否处于禁用状态，并在任何可按压元素挂载期间共享按压控制器的 window 与 document 监听器，还通过 tooltip 的层共享手势计数器的 document 监听器（每页安装一次）；它不拥有任何观察者，忙碌播报每段忙碌期只触发一次。已启用的开关还会向共享手势宿主添加一个使用方，其监听器每页安装一次；在精细主指针下，宿主在其轨道周围的元素上挂一个被动的 `pointerdown` 监听器（`spec:AST-094` FR24）。开关不自行添加 `click` 监听器：等待浏览器 click 的一次抬起会订阅 window 的共享输入流，直到该 click 到来或等待耗尽。

## Accessibility contract

触摸呈现不改变 Switch 的可访问名称、switch 角色、选中状态、忙碌状态、描述与状态关联，以及禁用行为，它们在任何其他指针下也是如此。

Switch 绑定到 `spec:AST-021` 下的共享开关模式可访问性契约。该绑定拥有由标准推导出的结果——角色、可访问名称、对外暴露的开/关状态、描述、禁用暴露与不可操作性、指针与键盘激活、指针取消，以及变更时焦点保持原位——覆盖 `__tests__/Switch.a11y.states.ts` 中列出的各代表状态。契约用鼠标检查指针取消：按下后滑出会让开关保持不变；在手指下，按下后滑出会切换它，依据 `spec:AST-020` FR9 的可逆切换例外（DEC-5、FR15）。回调载荷、表单参与、禁用原因 tooltip 的组成与样式仍归 Switch 所有，并留在 `Switch.test.tsx` 中。

- **AR1 — 禁用可达性。** FR7 满足 `spec:AST-085` FR1、FR5 与 FR6。
- **AR2 — 忙碌。** FR6；语音输出遵循 `spec:AST-009`。
- **AR3 — 非颜色状态。** FR11。

## Current-state impact

- **禁用时的调用方处理器（FR7）。** `onClick` 之外的调用方 DOM 处理器，例如 `onKeyDown`，在禁用时仍会执行，这违反了 `spec:AST-085` FR2。
- **根上的调用方 ARIA（FR12）。** 调用方的 `aria-label` 与其他 ARIA 属性，除 `aria-labelledby` 与 `aria-describedby` 之外，落在字段根而不是开关 input 上，这违反了 `architecture:public-component-api` INV5。
