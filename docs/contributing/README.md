# 贡献指南

这些指南将当前 Astryx 所有者记录转化为实际的贡献步骤。它们不制定策略，也不取代架构、规范、族契约或组件契约。

- [拉取请求意图](pull-requests.md)：选择一个主要意图，使用匹配的模板，并提供正确的证据，而不吸收搭车变更。
- [预审查](pull-requests.md#review-your-change-before-you-ask-for-review)：在请求审查之前，运行 `pnpm review:pre` 和检查清单。
- [API 约定](api-conventions.md)：塑造、提议、实现和审查公共组件 API。
- [CLI 约定](cli-conventions.md)：提议、实现和审查对 `packages/cli` 命令表面的更改。
- [编写规范记录](spec-writing.md)：六个月测试、作者在审查前对记录运行的评分准则，以及记录拉取请求所报告的结果。
