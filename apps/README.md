# /apps

用于开发、文档和视觉测试的应用包。

<!-- SYNC: When files in this directory change, update this document. -->

| 目录              | 角色     | 用途                                                          |
| ----------------- | -------- | ------------------------------------------------------------- |
| `docs/`           | 文档     | 设计系统的文档网站                                            |
| `example-nextjs/` | 示例     | 面向源码分发使用者的 Next.js 参考应用（Babel + PostCSS 路径） |
| `example-vite/`   | 示例     | 面向源码分发使用者的 Vite + React 参考应用（unplugin 路径）   |
| `sandbox/`        | 开发     | 本地开发与测试环境                                            |
| `storybook/`      | 视觉测试 | 用于组件开发和视觉文档的 Storybook                            |
