11 月 12 日，我们在 Meta 旧金山办公室接待了湾区设计系统社区的成员，共度了一个探讨“如何为人和 agent 构建设计系统”的夜晚。到场的有设计系统从业者、产品设计师、前端工程师、Astryx 贡献者，以及正在探索 agent 如何改变界面构建方式的人们。

当晚的核心是一个愈发切题的问题：**当 agent 已经能独立生成看起来很有说服力的界面时，设计系统还有价值吗？**

Astryx 团队分享了构建一个同时面向人和 agent 的开源系统的经验。我们讨论了为什么“看起来有说服力”的产出并不总是可信，以及恰当的指导、有意义的约束、评估方法和反馈闭环如何改善 agent 的产出。来自 Astryx 的例子展示了：更清晰的组件 API 如何避免错误假设，约束如何守住无障碍要求，评估又如何揭示问题究竟出在 agent、实现，还是设计系统本身。

![在 Meta 旧金山办公室，一位演讲者与就座的 Meetup 观众讨论生成式界面。](/blog/astryx-meetup-are-design-systems-still-valuable/photo-01.jpg)

![一位演讲者在幻灯片旁发言，幻灯片的主题是如何让好结果更容易复现。](/blog/astryx-meetup-are-design-systems-still-valuable/photo-02.jpg)

在活动的问答环节，Astryx 团队成员与一位来自 Vercel 的特邀嘉宾一起，就这些理念在实践中的落地展开了更广泛的对话。讨论涉及：当 agent 从意图直接走向界面时，构建者的角色如何变化；团队如何区分模型、设计系统和工作流层面的失败；以及责任应当如何在设计系统、agent 平台和产品团队之间划分。观众的提问和案例也带来了设计系统社区不同角度的声音。

![Meetup 问答环节，四位嘉宾坐在座位上，手持麦克风。](/blog/astryx-meetup-are-design-systems-still-valuable/photo-03.jpg)

![一位特邀嘉宾对着麦克风发言，另一位嘉宾在旁倾听。](/blog/astryx-meetup-are-design-systems-still-valuable/photo-04.jpg)

![小组讨论期间，一位观众提问。](/blog/astryx-meetup-are-design-systems-still-valuable/photo-05.jpg)

有一个共识贯穿了当晚的讨论：更快的生成速度并不会让共享系统变得不重要，反而提升了把产品意图、有效选择和质量信号明确表达出来的价值。当一个问题可能在大量生成界面中重复出现时，改进共享的源头，就能让之后的每一个结果都更可靠。

![Meetup 参与者在高脚桌旁三五成群地交谈。](/blog/astryx-meetup-are-design-systems-still-valuable/photo-06.jpg)

感谢每一位到场、提问并分享自己工作所见的朋友。这些观点会持续影响我们如何构建 Astryx，以及我们如何看待人、agent 与设计系统之间不断演变的关系。
