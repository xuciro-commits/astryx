# 运动测量

这是触摸呈现所需的一份 UIKit 参考采集清单。`uikit/` 中每个 `GUESS` 或 `webkit` 值都引用其中一个 ID（`@measure`），若此处缺少某个被引用的 ID，`uikit/uikit.test.ts` 就会失败。当某项采集完成后，其数值会替换 `uikit/` 中的猜测值（标记为 `@source measured: <app>, iOS <version>, <method>, <date>`）。

所有项目都在最新的 iOS 模拟器运行环境上执行（iOS 26.x，若已安装则用 27.x）；标记 † 的行还需在 iOS 18 上执行，以取得玻璃效果之前的差值。使用 iPhone 16 级设备、3× 缩放、带时间戳记录的真实 HID 触摸。

## 方法

- **A，动画转储**（精确参数）：一个插桩的 UIKit 应用记录添加到图层上的每个 `CAAnimation`（`-[CALayer addAnimation:forKey:]`）：视图类、键、键路径、类、from / to / by、additive、begin time、duration、timing-function 控制点，以及 `CASpringAnimation` 的 mass、stiffness、damping、initialVelocity、settlingDuration、allowsOverdamping。适用于 UIKit 在进程内做动画的一切。
- **B，录屏**（内置应用上的真值）：60 fps 录像（可用时为 120 fps），逐帧跟踪移动边缘得到 x(t)，用最小二乘拟合为弹簧（response、damping ratio）或曲线，并与 A 对比。
- **C，逐帧日志**：一个 `CADisplayLink` 记录器写入时间（`CACurrentMediaTime()`）、触摸流（`UIWindow.sendEvent`）、`contentOffset`，以及被测视图的呈现帧 / 变换 / alpha，同时由一个 UI 测试驱动已知速度的拖拽（`press(forDuration:thenDragTo:withVelocity:thenHoldForDuration:)`）。
- **D，读取**：直接打印某个 SDK 常量、计算属性或私有 style-provider 值（通过 harness 或调试器）。
- **H，触感日志**：swizzle `UIFeedbackGenerator` 及其子类的触发方法（`impactOccurred`、`impactOccurredWithIntensity:`、`selectionChanged`、`notificationOccurred:` 以及私有子类的方法）和 `AudioServicesPlaySystemSound*`；记录类、样式、时间戳。录制音频。
