# /packages

Astryx 设计系统发布的 npm 包。

<!-- SYNC: When files in this directory change, update this document. -->

| 目录      | 包                      | 用途                                                               |
| --------- | ----------------------- | ------------------------------------------------------------------ |
| `core/`   | `@astryxdesign/core`    | 核心 UI 组件、主题系统和工具                                       |
| `cli/`    | `@astryxdesign/cli`     | CLI 工具：组件文档、模板、脚手架、codemod                          |
| `build/`  | `@astryxdesign/build`   | 用于 StyleX 源码构建的构建插件（Babel、PostCSS、Vite）             |
| `themes/` | `@astryxdesign/theme-*` | 视觉主题（neutral、butter、chocolate、matcha、stone、gothic、y2k） |
| `vega/`   | `@astryxdesign/vega`    | Vega/Vega-Lite 图表封装（仅 canary）                               |
| `charts/` | `@astryxdesign/charts`  | 图表组件——基于 peer 引擎的可主题化封装（仅 canary）                |
| `lab/`    | —                       | 实验性组件（未发布）                                               |
