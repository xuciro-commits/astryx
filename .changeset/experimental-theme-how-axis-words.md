[experimental] `astryx experimental theme editor how`："inline"、"block"、"horizontal" 和 "vertical" 只有在紧邻其所限定的内边距时才表示某一边的内边距（"inline padding"、"padding-inline"、"padding 8px vertical"），绝不会作为部件名称中的一个词，因此 "inline code padding 4px" 和 "block quote padding 8px" 会设置该部件的每一边。
