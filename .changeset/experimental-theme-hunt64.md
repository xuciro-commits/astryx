[experimental] `astryx experimental theme editor`：输入清理会贯彻到底。引号仅在限定值时才会被映射（任意形态的同类弯引号，例如 „Inter“ 或 ‚Inter‘、«»、‹›、字体名周围的全角引号和反引号都会变成直引号，未配对的弯引号则变成它所代表的直引号），带引号的 CSS 字符串保留其内容，包括弯引号、不换行空格和 `;`；保存的值也以同样方式检查，值周围的引号会按其本来名称命名。从 JSON 粘贴的条目（`"accent": "#e11d48"`、`{"accent": "#e11d48"}`）或带有复制杂质的条目（末尾逗号、多余的引号或括号、开头的 `=` 或 `:`、引号外 `;` 之后的第二个声明）会按值读取；带引号的刻度盘值会提示该值；令牌名称中的类似破折号字符会作为其连字符；`textSize` 和 `text_size` 就是 text-size。字体堆栈按字体族读取：末尾逗号会被去掉，多包一对引号的堆栈会被解开，空字体族会被拒绝。`--mode` 会像值一样清理，近似拼写错误会在建议中保留 `--mode`。带有零散空格、引号、其他字母或粘贴的 `corners: pill` 的已保存刻度盘值会以清理后的形式提供，并与键入值一样经相同的输入清理读取；仅包含空文件夹的主题文件夹对于 `new` 来说算作空；在 set 或 undo 中拼错的主题名（`T`、`themes/t`、`./t`）会提示使用主题名称的同一命令。
