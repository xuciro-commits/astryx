[experimental] `astryx experimental render`：渲染后的文件现在会向接下来打开它的任何人自我说明。文件顶部的一段说明会列出生成它的 CLI 版本和渲染格式、页面路径、它携带的文件以及用于渲染的包，并给出取回源码并再次渲染的准确命令；内嵌源码之后的一小段说明会重复返回方式。`--reverse` 会报告渲染格式、CLI 版本（`renderedBy`）、这些包以及显式指定的 `--title`（`title`），并且对于本版本渲染的文件，报告是否有人在渲染后更改了标记（`edited`，按浏览器读取该文件的方式读取，因此途中行尾发生变化的副本不算被编辑），以及每处文本更改（`edits`：原来是什么、现在是什么，以及保存旧文本的还原文件和行号，位于模块或其导入的 JSON 数据中，也包括跨行换行之处）。如果文件的渲染格式比 CLI 能读取的更新，则会被新的 `ERR_RENDER_NEWER_FORMAT` 拒绝，该错误会指明写入它的 CLI 版本；声明的 CLI 版本不是语义版本的文件会作为损坏文件被拒绝，因此任何打印的命令都不会携带它，并且打印命令从接收文件取得的每个路径都会加引号。渲染格式保持为 1，因此较早的 CLI 仍能读取本版本写入的文件，除非文件携带 `.mts`、`.cts` 或 `.cjs` 模块——这类文件会声明格式 2，以便读取渲染格式的 CLI 指明读取它的 CLI；0.7.16 及更早版本会将其作为损坏文件拒绝。
