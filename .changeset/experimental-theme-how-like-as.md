[experimental] `astryx experimental theme editor how` 仅在比较形式中把 "like" 和 "as" 理解为比较（"as round as buttons"、"the same padding as cards"、"rounded like buttons"、"like the dialogs are"）："make components like dialogs and drawers rounder" 会更改这些部件，而 "use red as the button background" 会设置该值。更亮或更暗的颜色角色会以其自身值为起点、按同样的方式调整其深色一半，答案检查会在两种模式下按所要求的方式核对颜色（深色模式下文本和边框的对比度）和尺寸。"A light tint of the accent" 是强调色与透明色混合，绝不是完整的强调色。
