[experimental] `astryx experimental theme editor how`：读取 padding 方位词时会去掉部件名称，因此 "code block padding" 和 "top nav padding" 会设置该部件的每一边。"Card padding bigger (or smaller) than button padding" 会在按钮 padding 的基础上增加（或减少）一档，而绝不会复制它。诸如 "16 x 16" 的尺寸对表示大小，绝不表示数量。
